# Beer Portfolio PRD

## 项目概述

Beer Portfolio 是一页式个人开发者作品集网站，面向实习、求职和个人品牌建设，重点展示 AI 产品、微信小程序、Web 开发、产品设计和项目测试实践。

## 目标用户

- 招聘人员：快速查看个人定位、技术能力、项目完整度、简历和联系方式。
- 技术面试官：查看技术栈、项目架构、个人职责、问题解决过程、测试结果和 GitHub 仓库。
- 产品或设计面试官：查看需求分析、功能设计、页面结构、UI 设计逻辑、用户体验和项目复盘。
- 老师与同学：查看课程项目、小程序页面、功能完成度、技术说明和项目成果。

## 核心原则

- 内容优先，避免炫技动画。
- 一页完成主要浏览，只让项目详情、文章和简历进入独立页面。
- 每个项目必须说明项目背景、个人职责、核心功能、技术栈和项目结果。
- 保持真实克制，不虚构工作经历、项目数据和技能水平。

## 信息架构

首页顺序：

```text
个人介绍
-> 关于我
-> 经历
-> 精选项目
-> 其他项目
-> 文章与复盘
-> 联系方式
```

核心项目详情页：

```text
/projects/paipa
/projects/travel
/projects/hetao
/projects/resume-tool
```

## P0 范围

- 左侧固定个人信息区。
- 右侧自然滚动内容区。
- 锚点导航与滚动高亮。
- About 模块。
- Experience 模块。
- 4 个精选项目。
- 其他项目模块。
- 联系模块。
- GitHub、邮箱和简历入口。
- 移动端单栏适配。
- 项目独立详情页。
- 404 页面。
- SEO 基础配置。
- 部署到公开地址。

## P1 范围

- 文章模块。
- 项目图片灯箱。
- 页面进入动画。
- 阅读进度。
- 访问统计。

## P2 范围

- 深浅主题切换。
- 中英文切换。
- 项目搜索。
- 文章搜索。
- CMS。
- AI 个人助手。

## 非目标

- V1 不开发复杂联系表单。
- V1 不使用数据库或 CMS。
- V1 不做大面积粒子背景、3D 模型、复杂滚动劫持、过多玻璃卡片或无意义技能百分比。

## 推荐技术栈

- Next.js App Router。
- TypeScript。
- Tailwind CSS。
- MDX。
- Motion for React。
- Lucide React。
- 本地 TS 数据文件。

## 内容数据

项目和经历使用本地配置文件：

```text
src/data/profile.ts
src/data/experience.ts
src/data/projects.ts
src/data/notes.ts
```

项目详情和文章使用 MDX：

```text
content/projects/
content/notes/
```
